# Keyboard Shortcuts

## Viewer

| Key | Action |
|---|---|
| `Space` | Play / Pause |
| `←` / `→` | Previous / Next frame |
| `↑` / `↓` | Jump 10 frames forward/backward |
| `Shift+←` / `Shift+→` | Jump 1 second |
| `Ctrl+←` / `Ctrl+→` | Jump 5 seconds |
| `Home` | Go to first frame |
| `End` | Go to last frame |
| `I` | Set In point |
| `O` | Set Out point |
| `Alt+I` / `Alt+O` | Clear In/Out |
| `F` | Fit viewer to window |
| `Shift+F` | Full screen viewer |
| `Option+F` / `Alt+F` | Enhanced viewer (larger) |
| `Cmd+F` / `Ctrl+F` | Cinema viewer (full frame) |
| `Scroll` | Zoom in/out |
| `Click+drag` | Pan image |
| `Right-click` | Reset zoom/pan |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |

## Playback

| Key | Action |
|---|---|
| `J` | Play reverse (press multiple times = 2x, 4x) |
| `K` | Pause (with J/L: toggle between play and pause) |
| `L` | Play forward (press multiple times = 2x, 4x) |
| `Shift+J` / `Shift+L` | Scrub reverse/forward |
| `Number keys 0-9` | Go to 0-90% of clip duration |

## Node Editor

| Key | Action |
|---|---|
| `Alt+S` / `Option+S` | Add serial node |
| `Alt+P` / `Option+P` | Add parallel node |
| `Alt+L` / `Option+L` | Add layer node |
| `Alt+Y` / `Option+Y` | Add splitter/combiner |
| `Ctrl+D` | Bypass selected node |
| `D` | Disable/enable selected node |
| `S` | Solo selected node |
| `Delete` / `Backspace` | Delete selected node |
| `Ctrl+C` | Copy node |
| `Ctrl+V` | Paste node |
| `Ctrl+A` | Select all nodes |
| `Middle-click drag` | Pan node graph |
| `Scroll` | Zoom node graph |
| `Ctrl+Scroll` | Zoom in/out node editor |
| `F` | Frame all nodes (fit to view) |
| `Click + drag on socket` | Create connection |
| `Click on existing edge` | Select edge |
| `Delete (on edge)` | Remove connection |
| `Right-click on node` | Context menu |
