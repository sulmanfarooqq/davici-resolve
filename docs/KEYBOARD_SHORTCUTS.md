# Keyboard Shortcuts

Complete reference for all keyboard shortcuts in davici-resolve.

---

## File Operations

| Shortcut | Action |
|----------|--------|
| `Ctrl+O` | Open Image |
| `Ctrl+Shift+O` | Open Video |
| `Ctrl+L` | Open LUT |
| `Ctrl+S` | Save Project |
| `Ctrl+Shift+S` | Save Project As |
| `Ctrl+Q` | Quit |

---

## Edit Operations

| Shortcut | Action |
|----------|--------|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+R` | Reset Grade |

---

## Playback

| Shortcut | Action |
|----------|--------|
| `Space` | Play / Pause |

---

## Viewer

| Action | How |
|--------|-----|
| Zoom in/out | Scroll wheel |
| Pan | Left-click drag |
| Fit to window | Right-click |
| Color pick | Click "Pick" button, then click on image |

---

## Notes

- All shortcuts are active when the main window is focused
- The Space bar shortcut for play/pause works even when a text field has focus
- Undo/Redo captures all grade parameter changes (color wheels, sliders, LUT)
